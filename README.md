# playrust

Rust 개념을 읽고, 예제를 실행해 보고, 코드 빈칸 채우기 퀴즈로 따라 하며 배우는 터미널 TUI 학습 앱입니다.
레슨은 `lessons/*.toml` 에 있습니다.

## 기능

- 레슨: 개념 설명과 예제 코드를 읽고, 예제를 로컬 `rustc` 로 실행. 예제 코드는 ` Example ` 라벨이 달린 테두리 박스 안에 표시되고, 설명과 함께 스크롤됩니다. 긴 코드 줄은 박스 안에서 글자 단위로 접힙니다. 예제 편집도 화면 전환 없이 이 박스 안에서 바로 합니다.
- 퀴즈: 코드 빈칸 채우기, 힌트·정답 보기, 내 답으로 실행
- 구문 강조: nvim 테마 onedarkpro `onedark_dark` 에서 Rust 코드가 보이는 색(nvim-treesitter + rust-analyzer)을 truecolor 로 그대로 씁니다. 설명 속 인라인 코드도 같은 색으로 강조하고, 색이 없는 토큰(연산자 등)은 nvim 마크다운 인라인 코드처럼 초록으로 칠합니다.
- 목차: 레슨은 목차 팝업(`Ctrl+L`)에서 고릅니다. 팝업 제목에 완료한 레슨 수, 줄마다 레슨 요약(화면이 좁으면 `…` 로 줄임)이 표시되고, nvim 의 CursorLine 처럼 고른 줄을 진한 초록 바탕(`#003f00`)으로 표시합니다.
- vim 스타일 편집: 퀴즈 빈칸과 레슨 예제 코드를 앱 안에서 vim 키로 편집하고 바로 실행. 현재 모드는 nvim lualine 처럼 하단 줄 왼쪽에 색 배지(` NORMAL ` 초록, ` INSERT ` 파랑, leader 대기 ` LEADER ` 보라)로 표시되고, 편집 중인 코드 박스(퀴즈 ` Rust `, 편집 중인 예제 ` Example `) 테두리도 같은 모드 색이 됩니다.
- 화면 문구: 앱이 그리는 제목·안내·피드백 문구는 영어이고, 레슨 내용(제목, 요약, 설명, 문제, 힌트, 해설)은 한국어입니다.

구문 강조 색:

## 요구사항

- Rust 1.88+ (edition 2024)
- 예제·내 답 실행 기능은 로컬 `rustc` 를 사용합니다 (Rust 설치 시 함께 설치됨).
- 색은 truecolor(24비트) 로 그리므로 truecolor 를 지원하는 터미널을 권장합니다. 팔레트가 어두운 테마라 어두운 배경에서 잘 읽힙니다.

## 실행

```sh
cargo run          # 레슨 1 보기 위에 목차 팝업이 열린 상태로 시작
cargo run -- 3     # 3번 레슨 보기에서 시작 (팝업 없음)
```

| | `q` | 확인 후 종료 |

| | `Ctrl+L` | 목차(레슨 목록) 팝업. `↑`/`↓`, `j`/`k`, `gg`/`G` 로 고르고 `Enter` 로 그 레슨 보기 열기, `Esc`, `q`, `Ctrl+L` 로 닫기. 퀴즈 중이면 퀴즈를 떠나고, 예제 편집 중이면 편집을 마칩니다 (수정본 유지, 같은 레슨이면 실행 출력과 스크롤도 유지) |
| | `?` | 키 도움말 팝업 (Insert 모드와 `r` 다음에는 글자 입력). `↑`/`↓`, `j`/`k` 로 한 줄, `PgUp`/`PgDn`, `Ctrl+B`/`Ctrl+F` 로 한 화면, `Ctrl+U`/`Ctrl+D` 로 반 화면 스크롤, `?`, `Esc`, `q`, `Enter` 로 닫기 |

하단 줄에는 화면별 주요 키와 `^L lessons`, `? help` (Insert 모드에서는 `?` 가 글자로 입력되어 빠짐) 가 표시되고, 전체 키는 `?` 팝업에서 볼 수 있습니다. 퀴즈 하단 줄에는 레슨 보기로 가는 `^O lesson`, 퀴즈를 풀다 온 레슨 보기에는 돌아가는 `^O back to quiz`, 예제 편집 중에는 편집을 마치는 `^O done editing` 이 표시됩니다.

화면 이동은 목차 팝업(`Ctrl+L`)으로 합니다. 습관적으로 누르는 `Esc` 때문에 화면이 바뀌거나 종료 확인이 뜨지 않도록, `Esc` 는 Insert → Normal 전환, 팝업 닫기, 레슨 화면의 검색 강조 지우기에만 씁니다. 같은 이유로 예제 실행·편집·원본 복원, 퀴즈 힌트·정답 보기도 한 글자가 아니라 leader 키 `,` 다음 키로 합니다.

- `,` 를 누르면 하단 줄이 ` LEADER ` 배지와 다음 키 안내로 바뀝니다. 그 밖의 키는 leader 를 취소만 합니다 (시간 제한 없음). 결과 화면에는 leader 로 할 일이 없어 `,` 를 눌러도 아무 일 없습니다. `Esc` 바로 뒤에 `,` 를 빨리 눌러 터미널이 Alt+`,` 로 합쳐 보내도 `Esc` 다음 `,` 로 받습니다.

  | 다음 키 | 동작 | 화면 |
  | --- | --- | --- |
  | `r` | 지금 화면의 코드 실행 (레슨은 예제, 퀴즈는 내 답) | 레슨 보기·예제 편집, 퀴즈 |
  | `e` | 예제 편집 시작 | 레슨 보기 |
  | `R` | 원본 예제로 되돌리기 | 레슨 보기 |
  | `h` | 힌트 켜고 끄기 | 퀴즈 |
  | `a` | 정답 보기 (점수 미반영) | 퀴즈 (답을 입력하는 중) |

- `?` 처럼 Insert 모드와 `r` 다음에는 `,` 가 글자로 입력됩니다. Insert 에서 실행하려면 `Esc` 로 Normal 에 들어간 뒤 `,r` 을 누릅니다 (힌트 `,h`, 정답 보기 `,a` 도 `Esc` 후). leader 키와 같은 일을 하는 `Ctrl` 키는 따로 두지 않습니다. 퀴즈에서 아래 패널(힌트·해설·실행 출력)이 비어 있으면 그 자리에 팁이 한 줄 표시됩니다 (빈칸이 둘 이상이면 `Tab` 빈칸 이동, 아니면 vim 키). 예제 편집 중에는 레이아웃이 보기와 같도록 팁 줄 대신 Normal 하단 줄에 `i/a/o insert` 를 안내합니다.

레슨 예제 편집:

- `,e` 를 누르면 화면 전환 없이 레슨 화면의 ` Example ` 박스 안에서 바로 편집합니다. 제목·설명·박스 위치는 그대로이고, 박스 안에 커서가 생기며 Normal 모드로 시작합니다. `i`, `a`, `o` 등으로 Insert 모드에 들어가 입력합니다.
- 커서는 화면에 보이던 예제 줄 안에 놓입니다 (처음 편집이면 첫 줄, 스크롤해 둔 화면이면 보이는 줄로 옮김). 그래서 편집을 시작해도 화면이 움직이지 않습니다. 예제가 화면에 전혀 보이지 않았을 때만 커서 줄이 보이게 스크롤합니다.
- 긴 줄은 보기와 똑같이 박스 안에서 글자 단위로 접히고, 커서도 접힌 자리에 표시됩니다 (한글 같은 2칸 문자 포함, 탭은 4칸 간격 탭 멈춤까지 공백으로 펼침). 편집을 시작하거나 마쳐도 박스 높이와 코드 줄 위치가 바뀌지 않습니다.
- 편집 중에는 커서 줄이 늘 보이도록 설명과 박스 전체가 커서를 따라 스크롤됩니다. 화면 밖의 첫 줄·끝 줄로 가면 박스 위·아래 테두리까지 보입니다. 설명을 다시 보려면 편집을 마칩니다 (보기에서는 `j`/`k` 로 커서 이동, `PgUp`/`PgDn`, `Ctrl+F` 등으로 화면 스크롤).
- 하단에 ` INSERT ` / ` NORMAL ` 모드 배지, 코드 테두리 오른쪽 위에 커서 위치 `행:열` 이 표시됩니다. 코드 테두리도 모드 색(Insert 파랑, Normal 초록)입니다.
- 커서 모양은 Insert 에서 막대, Normal 에서 블록입니다 (퀴즈 빈칸도 같음, 터미널이 지원하는 경우).
- 편집 중에는 `q` 를 눌러도 종료되지 않고, `Esc` 는 Insert → Normal 만 합니다 (습관적인 `Esc` 로 편집이 끝나지 않음). `Enter` 도 편집기 키입니다.
- 편집은 `Ctrl+O` 로 마칩니다 (같은 화면 그대로). `Ctrl+L` 목차에서 같은 레슨 `Enter` 도 같고, 다른 레슨을 고르면 편집을 마무리한 뒤 이동합니다.
- 예제를 수정하면 제목 옆에 "(modified)" 가 표시되고, 보기 화면의 예제와 `,r` 실행도 수정본을 씁니다.
- 편집을 마칠 때 원본과 같으면(`u` 로 되돌린 경우 포함) 수정본을 버리고 "(modified)" 도 사라집니다.
- 수정본은 레슨별로 실행 중에만 유지됩니다 (파일에 저장하지 않음). `,R` 로 원본으로 되돌립니다.

퀴즈:

- 빈칸 입력은 Insert 모드로 시작해 바로 타이핑할 수 있습니다. 하단에 ` INSERT ` / ` NORMAL ` 배지로 현재 모드가 표시되고, 빈칸을 입력하는 동안 ` Rust ` 박스 테두리도 모드 색입니다. 현재 빈칸 자체는 모드와 상관없이 반전으로만 표시해 채점 결과(빨간·초록 바탕)와 헷갈리지 않게 했습니다.
- `Tab`/`Shift+Tab` 으로 빈칸을 옮겨도 모드가 유지됩니다. Insert 면 다음 빈칸 끝에서 이어 쓰고, Normal 이면 Normal 그대로입니다.
- 오답이면 커서가 첫 번째 틀린 빈칸으로 이동합니다 (모드 유지는 `Tab` 과 같음).
- 채점한 빈칸은 바탕색으로 표시합니다. 틀린 빈칸은 빨간 칸, 맞은 빈칸은 초록 칸이라 빨간 글자인 변수와 헷갈리지 않습니다.
- 정답을 맞히거나 정답 보기를 한 뒤에는 입력이 잠기고(`j`/`k`, `↑`/`↓` 는 코드 스크롤), `Enter` 로 다음 퀴즈로 넘어갑니다.
- `Ctrl+O` 로 레슨 보기와 퀴즈를 오갑니다. 퀴즈 중 `Ctrl+O` (또는 `Ctrl+L` 후 `Enter`) 로 레슨 보기에 가도 입력·점수는 남아 있고, 레슨 보기에서 `Ctrl+O` 를 누르면 풀던 자리로 돌아갑니다. 퀴즈를 다 풀면(결과 화면) 다음 `Ctrl+O` 는 첫 퀴즈부터 다시 시작합니다. 레슨 보기의 스크롤·커서 위치는 퀴즈를 다녀와도 그대로입니다.
- 모든 퀴즈를 맞힌 레슨은 목차 팝업에 `✓` 로 표시됩니다 (실행 중에만 유지).
- 결과 화면에 점수가 표시됩니다.

### vim 키

퀴즈 빈칸(한 줄)과 레슨 예제(여러 줄) 편집에서 공통으로 씁니다. "(예제)" 표시가 있는 키는 예제 편집에서만 동작합니다.

| 모드 | 키 | 동작 |
| --- | --- | --- |
| Insert | 글자 | 입력 |
| | `Backspace`, `Delete` | 지우기 (예제는 줄 경계에서 줄 합치기) |
| | `Ctrl+W` | 커서 앞 단어 지우기 (줄 처음이면 `Backspace` 와 같음) |
| | `←`/`→`, `Home`/`End` | 커서 이동 |
| | `↑`/`↓` | (예제) 위 / 아래 줄 (퀴즈에서는 코드 스크롤) |
| | `Enter` | (예제) 줄바꿈, 들여쓰기 유지 |
| | `Tab` | (예제) 공백 4칸 |
| | `Esc` | Normal 모드 |
| Normal 이동 | `h` `l` `←` `→` | 왼쪽 / 오른쪽 (`Backspace` 는 `h` 와 같음) |
| | `0` `^` `$` | 줄 처음 / 첫 글자 / 줄 끝 (`Home` 은 `0`, `End` 는 `$` 와 같음) |
| | `w` `b` `e` | 다음 단어 / 이전 단어 / 단어 끝 |
| | `j` `k` `↑` `↓` | (예제) 아래 / 위 줄 |
| | `Enter` | (예제) 다음 줄 첫 글자 |
| | `gg` `G` | (예제) 첫 줄 / 마지막 줄 |
| | `/` `n` `N` | (예제) 검색 / 다음 일치 / 이전 일치 |
| Normal 입력 전환 | `i` `a` | 커서 앞 / 뒤에서 Insert |
| | `I` `A` | 줄 첫 글자 / 줄 끝에서 Insert |
| | `o` `O` | (예제) 아래 / 위에 새 줄을 열고 Insert (들여쓰기 유지) |
| Normal 수정 | `x`, `Delete` | 글자 삭제 |
| | `D` | 커서부터 줄 끝까지 삭제 |
| | `C` | 줄 끝까지 삭제 후 Insert |
| | `s` | 글자 삭제 후 Insert |
| | `S`, `cc` | 들여쓰기는 남기고 줄 내용을 지운 뒤 Insert |
| | `dd` | 줄 삭제 (레지스터에 저장, 퀴즈는 빈칸 비우기) |
| | `dw` | 단어 삭제 |
| | `cw` | 단어 삭제 후 Insert |
| | `ciw` `diw` | 커서 아래 단어 전체를 지운 뒤 Insert / 지우기만 (공백 위면 이어진 공백) |
| | `r{문자}` | 커서 글자를 `{문자}` 로 바꾸기 |
| | `u` | 되돌리기 (최대 100단계, Insert 에서 `Esc` 까지 입력한 내용이 한 단계) |
| | `yy` | (예제) 줄 복사 (레지스터에 저장) |
| | `p` `P` | (예제) 레지스터의 줄을 아래 / 위에 붙여넣기 |

- 레지스터는 줄 단위 하나뿐이고 `dd`/`yy` 만 채웁니다. `x`, `dw`, `diw`, `D` 등으로 지운 내용은 레지스터에 들어가지 않습니다.
- 지원하지 않는 것: 숫자 반복(`3j`, `2dd`), 비주얼 모드, `:` 명령(`:w`, `:q`), 정규식 검색과 `?` 뒤로 검색(`?` 는 도움말), 퀴즈 화면 검색, redo (`Ctrl+R`).

## 코드 실행

예제 실행(보기 모드와 편집 중 Normal 의 `,r`)과 퀴즈 내 답 실행(Normal·잠김의 `,r`)은 로컬 `rustc` 로 임시 디렉터리에서 컴파일한 뒤 실행합니다.

- 실행 중(컴파일 약 1초, 최대 5초)에는 `Running…` 이 표시되고 화면이 잠시 멈춥니다.
- 결과는 ` Output ` 패널(퀴즈는 아래 패널)에 `Run OK` 또는 `Run failed` 와 함께 표시됩니다. 출력의 탭은 4칸 간격으로 펼쳐 보입니다. 출력이 패널보다 길면 테두리에 스크롤 키가 표시됩니다 (레슨 보기에서는 `PgUp`/`PgDn` 이 본문 스크롤이라 ` ,e then PgUp/PgDn `: `,e` 로 편집에 들어가 스크롤).
- 실행 시간은 5초로 제한됩니다.
- 비정상 종료(`(exited abnormally: …)`), 시간 초과(`Timed out: stopped after 5s.`), 출력 잘림(200줄 또는 16KB 초과, `... (output truncated)`)은 출력 끝에 표시됩니다.

## 레슨 추가

`lessons/NN-slug.toml` 파일을 추가합니다. 파일명 정렬 순서가 레슨 순서이고, 확장자를 뺀 파일명이 레슨 id 입니다.

```toml
title = "변수와 가변성"
summary = "let, mut, shadowing"
concept = '''
개념 설명. 문단은 빈 줄로 구분하고 인라인 코드는 `백틱` 으로 감쌉니다.
'''
example = '''
fn main() {
    let mut x = 5;
    x += 1;
    println!("{x}");
}
'''

[[quiz]]                # 레슨당 2~3개
prompt = "x 를 변경 가능하게 만드세요"
code = '''
fn main() {
    let ___ x = 5;
    x += 1;
}
'''
answers = ["mut"]       # 빈칸 `___` 순서대로 1개씩 (빈칸 1~3개)
hint = "가변(mutable)"
explanation = "변수는 기본이 불변이라 값을 바꾸려면 mut 가 필요합니다."
```

- `example` 과 정답을 채운 `code` 는 그대로 컴파일되는 완전한 프로그램이어야 합니다.
- 정답 판정: 입력과 정답 모두 공백 문자를 전부 지운 뒤, 대소문자를 구분해 완전히 같아야 정답입니다 (`& mut` 과 `&mut` 은 같은 답).
- 빈칸은 토큰 중간에도 둘 수 있습니다 (예: `1___5` 의 정답 `..=`).
